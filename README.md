# ninkatsu-ayumi-assets

Instagram [@ninkatsu_ayumi](https://www.instagram.com/ninkatsu_ayumi/)（妊活の歩み方）の
カルーセル投稿用カード画像の置き場です。

Instagram Graph API は「公開URLのJPEG」しか受け付けないため、自動投稿用にここでホストしています。

- `cards/<投稿ID>-<番号>.jpg` … 1080×1080 JPEG。番号がそのままカルーセルの並び順
- 投稿IDは元記事の番号＋前後編（例: `431a` = article/431 の前編）

出典サイト: https://ninkatsu-ayumi.com/
